# 수집 프로젝트 상태

기준일: 2026-11-03

## 확정

- 용인시 생활여가·문화·체육 MVP만 수집한다.
- 독립 저장소에서 원본 파일과 수집 이력을 관리한다.
- 기존 분석 서비스는 정제·검증·DB 적재를 담당한다.

## 실행 확인

- 도서관 신간도서 포털 XLSX 다운로드 및 재실행 중복 판단
- 기흥구 이벤트 정보 포털 CSV 다운로드 및 재실행 해시 비교
- 수지구 생활체육 공식 HTML 원본 다운로드 및 재실행 중복 판단
- 원본별 SHA-256과 수집 메타데이터 저장
- 단위 테스트 및 Python 문법 검사

## 아직 미검증

- 공공시설개방정보 Open API 실제 호출: 공공데이터 인증키 미설정
- n8n 실제 가져오기·스케줄 실행: n8n 실행 환경 미제공
- 수지구 프로그램의 포털 CSV 파일: 현재 공식 페이지는 기관 바로가기
- 분석 서비스가 원본 저장소에 접근하는 전달 경로
- 기존 분석 프로젝트와 수집기 사이의 최종 3종 목록 일치
