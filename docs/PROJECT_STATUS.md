# 수집 프로젝트 상태

기준일: 2026-11-03

## 확정

- 용인시 생활여가·문화·체육 MVP만 수집한다.
- 독립 저장소에서 원본 파일과 수집 이력을 관리한다.
- 기존 분석 서비스는 정제·검증·DB 적재를 담당한다.

## 실행 확인

- 도서관 신간도서 포털 XLSX 1건(10,312,734바이트) 원본 보존 및 일일
  재다운로드 SHA-256 중복 판단
- 기흥구 이벤트 정보 포털 CSV 1건(59,856바이트) 원본 보존 및 일일
  재다운로드 SHA-256 중복 판단
- 수지구 생활체육 공식 HTML 원본 다운로드 및 재실행 중복 판단
- 파일 ID가 같은 경우의 내용 변경, HTML 위장 CSV, 빈/잘못된 파일, 일부 후보
  실패 시 기존 manifest 유지 로직
- 원본별 SHA-256, 수집일·데이터 기준일, HTTP 상태와 수집 메타데이터 저장
- API 페이지 수·전체 건수·필드 구조·주소·기준일 검증과 페이지 일괄 커밋 로직
- 성공/실패 점검 이력 저장(인증키와 인증 오류 원문 제외)
- 단위 테스트 11건 및 Python 문법 검사
- n8n 템플릿 JSON 구문과 Asia/Seoul 매일 07:00 일정, 실행 명령 확인
