## 수집 저장소의 Git 상태

수집·분석 최소 기능은 `09c71ca`로 `origin/main`에 이미 반영됐다. 이 문서는
두 VS Code 에이전트 사이의 소유권·검증 상태 전달을 추가한다. 분석 저장소가
별도 Git 저장소라면 그 저장소의 변경은 해당 에이전트가 별도로 검토·커밋한다.
